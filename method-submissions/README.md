# Submit a method to StatArena

Prepare these three items for a statistical method or model you want evaluated.

1. **Method link.** Provide a public link to a runnable implementation, such as a GitHub repository or a Hugging Face model page. Include access to any weights needed to run it.
2. **Research domain.** Select the domain you want the method evaluated on.
3. **Completed checklist.** Copy the [method checklist template](method-checklist.md) and answer each section. Include the [mediation method card](../mediation/method-card.md) if you are submitting to that benchmark.

Share the materials with the StatArena maintainers through the [team's method submissions guide](https://github.com/Statsinference/Statistical-Intelligence-Arena/blob/main/method-submissions/README.md). The team reviews each submission and evaluates eligible methods for the official leaderboard.
