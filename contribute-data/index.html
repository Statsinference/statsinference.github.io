Contribute data

Propose a simulated design or a real-data problem for statistical inference. Use one GitHub pull request per proposal.

Simulated DGP

Define the variables and write the complete structural equations for the simulation. Explain what the design tests, what motivated it and how to check the reference value.

Real-data problem

Give an answerable question, the study design and a public data link or authorized access route. Explain what the available data can identify. A reference estimate is welcome.

Real-data problem guide Job-training experiment example

Submit and review

  1. Fork the repository and copy the track template into its submissions/ directory. Include a DAG when it clarifies the causal assumptions. A short explanation also works.
  2. Open a pull request from your fork. Keep the proposal public-safe. A maintainer will arrange private sharing for generators, exact configurations and reference values intended for official evaluation.
  3. The automated check reports missing sections or layout errors. A maintainer reviews the statistical question, assumptions, evidence and reproducibility in the PR.
