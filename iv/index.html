How were the studies generated?

The fitting, selection and evaluation studies draw from the Ding, Qiu and Kennedy design families. The historical fitting and selection archives have 500 context rows and 64 query rows per study, with analytic nuisance targets for the query rows. The starter provides 96 separately generated studies. The evaluation is one pooled split with 665 Ding, 658 Qiu and 677 Kennedy studies. Each evaluation study has its own parameter draw. See the data-generating mechanisms and priors.

Identification assumptions and variable roles

Write D(z) for the treatment a unit would receive at instrument level z, and Y(d) for the outcome under treatment d. Compliers satisfy D(1) > D(0). The benchmark designs assume exclusion, monotonicity and instrument independence given the covariates. They give both instrument values positive probability given the covariates and a positive population first stage. The target is the ratio of the covariate-adjusted instrument effects on the outcome and on the treatment.

Run a baseline

Extract the starter ZIP, open its directory and run the commands below. The unadjusted Wald baseline divides the difference in mean outcomes across instrument groups by the difference in treatment rates. It uses a delta-method normal interval. Covariate-dependent instrument assignment can bias this unadjusted estimate.

python -m pip install numpy
python baseline.py dev/tables > predictions.csv
python score.py dev/truth.csv predictions.csv

After choosing your settings, replace dev with test in both commands to score the 32 starter test studies.

Official evaluation

Freeze your estimator and settings before opening the public scoring archive. For cross-fitting, preserve the supplied five folds. Both reference methods use the same fixed random split of the 500 rows for every study. Row indices start at 0 and fold labels run from 1 to 5.

Score all 2,000 studies with equal weight. Bias averages the errors, where each error is the estimate minus the population LATE. RMSE is the square root of the mean squared error. Error variance is the sample variance across studies with denominator 1,999. Coverage counts intervals containing the true effect, including either endpoint. Mean interval length averages the differences between upper and lower endpoints.

TabPFN-IV v0.3 and the leaderboard's RF + bootstrap method use five-fold cross-fitting and the same augmented inverse-probability-weighted LATE ratio. TabPFN-IV constructs an influence-function interval. The displayed forest clips the estimated instrument propensity to [0.05, 0.95] and uses a percentile interval from 50 whole-row bootstrap refits. Both forest variants and their predictions are included in the public scoring archive. View leaderboard results.

Submission format

Fill the prediction template in the evaluation inputs ZIP with one row per study. Keep the original table IDs and column names. Use finite values for the point estimate and endpoints, and put the lower endpoint at or below the upper endpoint.

table_id,estimate,ci_lower,ci_upper

Extract the public scoring archive and run the scorer with your predictions file.

python score.py truth.csv /path/to/predictions.csv

When reporting runtime, give the mean seconds per study and the hardware. Include the point estimate, confidence interval and any bootstrap work. Exclude model loading and warm-up.
