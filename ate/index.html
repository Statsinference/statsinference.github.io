Average Treatment Effect

How much does treatment change the outcome on average? Given one simulated study, estimate its population average treatment effect and return a two-sided 95% confidence interval.

ATE = E[Y(1) − Y(0)]

Data and splits

Each simulated study has 500 observations with baseline covariates X, binary treatment T and outcome Y. The ATE averages over the population underlying the study. Report effects in outcome units, or as probability differences for binary outcomes.

How were the starter studies generated?

The starter adapts Nie–Wager Setup A and a Benkeser et al. design. Train, development and test use disjoint parameter configurations. Each configuration yields two independently sampled tables and shares a fixed CATE query across the pair.

Run a baseline

Extract the starter ZIP and run these commands from its directory. The linear T-learner fits a separate outcome regression in each treatment arm and averages their fitted treatment–control differences over the study’s covariates. The 95% percentile interval uses 200 whole-row bootstrap refits.

python -m pip install numpy
python baseline.py --tables dev/tables --task ATE --output dev_predictions_ate.csv
python score.py --truth dev/truth_ate.csv --predictions dev_predictions_ate.csv --timings dev_predictions_ate.csv.timings.json

Choose settings on dev/, then run the same commands with test/tables and test/truth_ate.csv to score the public reference test.

Official evaluation

Freeze your method before evaluating the 2,000 studies. They come from 1,000 parameter configurations with two independent draws per configuration. Each study has a stable table ID, 2–10 covariates and a continuous or binary outcome. If you cross-fit, use the five treatment-stratified assignments in folds/ATE/ and preserve observation order.

The input ZIP omits population effects, generation parameters and an explicit replicate-pairing map. The same studies and their effect labels appeared in earlier public releases. The current collection is a fixed reference for comparison and reproducibility. Read the release history

For submitted predictions, signed bias, RMSE, empirical 95% coverage and mean interval length give each study equal weight. The variance metric uses the paired studies to estimate within-configuration sampling variance. Report inference time as mean seconds per study with the hardware used. Include point estimation and interval construction, including any bootstrap, and exclude model loading and warm-up.

In the existing leaderboard summary, the original evaluation report gives each of the 13 data-generating families equal weight. View ATE results

Submit a method

For ATE, fill predictions_ate_template.csv with one row per official study. Preserve each table_id, use finite numeric values and ensure ci_lower <= ci_upper.

table_id,estimate,ci_lower,ci_upper

The release asks for both the completed ATE and CATE prediction CSVs for maintainer scoring. Include your estimator, interval construction, training-data exposure and timing hardware.
