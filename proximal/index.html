Proximal Causal Inference

Given one observational study with proxies for an unmeasured confounder, estimate the conditional average treatment effect (CATE) at a supplied covariate query. Return one point estimate and a two-sided 95% interval per study.

τ(x*) = E[Y(1) − Y(0) | X = x*]

Data and splits

Each study contains 500 observations. The input columns are baseline covariates X1 and X2, the treatment-confounding proxy Z, the outcome-confounding proxy W, binary treatment A and continuous outcome Y. Each entry in queries.csv supplies an independent target point using X1 and X2.

Public starter kit

48 training, 16 development and 32 public reference test tables, with known effects, queries, a generator, a baseline and a scorer. All 96 studies were generated for this starter kit.

Identification and variable roles

The target averages the effect over the natural distribution of the outcome-confounding proxy W at the supplied covariate point. The confounder itself is latent. A proximal bridge estimator needs assumptions about the roles of both proxies and conditions that identify the bridge, including completeness. Describe the assumptions your method uses.

Run a baseline

Extract the starter kit, open its directory and run these commands. The starter fits a linear S-learner on covariates and treatment, with treatment-by-covariate interactions. It forms a 95% interval from 50 whole-row bootstrap refits. The fit uses only X1, X2 and A as predictors, so an unmeasured confounder can bias its estimate.

python -m pip install numpy
python baseline.py --tables dev/tables --queries dev/queries.csv --output dev_predictions.csv
python score.py --truth dev/truth.csv --predictions dev_predictions.csv

Use the public test split for a final local check after choosing your settings on dev.

Official evaluation

Fix your method before using the official inputs. The release preserves the 2,000 studies from the November 16 evaluation. Each study has its own sampled configuration and query. Cross-fitted methods and methods using context partitions should preserve row order and use the supplied treatment-stratified assignments in folds/<table_id>.csv.

Each study gets equal weight. Bias and RMSE use the signed point-estimation errors. Variance is the sample variance of those errors across studies, with denominator 1,999. Coverage is the fraction of intervals containing the true effect. Mean interval length averages the difference between upper and lower bounds.

The leaderboard displays normalized error and interval length metrics. Divide each study’s error and interval length by the sample standard deviation of its observed outcome before aggregation. The published source data also include results in original outcome units. Coverage and time have the same values at both scales. Report warm runtime per study, including point estimation and interval construction with all bootstrap refits. Include the hardware used. View results in original units

Submission format

Fill predictions_template.csv with one row for each official study. Keep the supplied IDs and return the effect and interval endpoints in original outcome units. Use finite values, with the lower endpoint at or below the upper endpoint.

table_id,estimate,ci_lower,ci_upper

Maintainers score predictions against the retained effects. Include the estimator, interval construction, training-data exposure and any timing details when sharing predictions. To submit a method for review, follow the method submission guide.
