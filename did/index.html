Difference-in-Differences

Given a simulated two-period panel, estimate the average treatment effect on the treated (ATT) in the post-treatment period and return a two-sided 95% confidence interval.

ATT = E[Y1(1) − Y1(0) | D = 1]

Data and splits

Each study contains 500 units. Its NPZ file supplies baseline covariates X, binary treatment D, and the post-minus-pre outcome change delta_y, in matching row order. Studies without observed covariates supply an X array with shape (500, 0). Use these three arrays as estimator inputs and return one estimate and one interval in outcome units per study.

Historical fitting data

10,000 adapter-training studies and 200 checkpoint-selection studies drawn from ten data-generating families, with population ATT labels.

How the studies were generated

The starter and evaluation sets draw from a 13-family prior, which adds three designs to the historical fitting prior. The pooled evaluation independently draws a family uniformly, then draws parameters and samples one study for that draw. The population ATT holds the generating family and parameters fixed and averages the post-period effect among units receiving treatment. Data-generating processes, priors and truth calculations

Run a baseline

Extract the starter ZIP and run these commands from the extracted directory. The baseline subtracts the control group's mean outcome change from the treated group's mean outcome change and uses a normal confidence interval. Designs that require covariate adjustment can bias this estimate.

python -m pip install numpy
python baseline.py dev/tables > predictions.csv
python score.py dev/truth.csv predictions.csv

Replace dev with test in the last two commands to score the starter's reference test split.

Official evaluation

Freeze the method before opening the public scoring archive. If the method uses cross-fitting, keep the supplied five treatment-stratified folds for the original fit and preserve row order. Row indices start at 0 and fold labels run from 1 to 5.

The scorer gives each study equal weight. Bias is the mean of estimate minus population ATT, RMSE is the root mean squared error, and error variance is the sample variance of those errors across studies with denominator 1,999. Coverage counts the share of intervals containing the true ATT including either endpoint. Mean interval length averages upper minus lower.

In the published comparison, PFN-DiD and the random-forest comparator estimate treatment propensities and the mean outcome change under control, then apply the same doubly robust DiD score. PFN-DiD uses an influence-function standard error. The forest uses the standard deviation from 50 full row-bootstrap refits, with new folds in each resample. Both report normal intervals. Prediction format

Fill the prediction template with one row per evaluation study. Keep each table ID. The estimate and interval endpoints must be finite, with the lower endpoint at or below the upper endpoint.

table_id,estimate,ci_lower,ci_upper

Extract the scoring archive and run the scorer using its truth.csv and the completed predictions file.

python score.py truth.csv predictions.csv

When sharing results, describe your estimator, interval procedure and data exposure. If you report runtime, include the mean estimation time in seconds per study and the hardware. To submit a method for review, follow the method submission guide. Open the DiD leaderboard
